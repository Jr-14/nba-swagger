# nba-swagger
NBA Swagger Docs. Documenting the undocumented

## Development

```bash
pnpm install
pnpm dev
```

`pnpm dev` starts Swagger UI and the Node proxy locally. `pnpm dev:pages` runs
the Pages/Worker/container stack and requires Docker.

See [development](docs/development.md) for commands and
[architecture](docs/architecture.md) for deployment and transport findings.
